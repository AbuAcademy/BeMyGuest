# Be My Guest

Repositório oficial de código-fonte, scripts e laboratórios dos livros **Be My Guest**, de Gustavo Abu.

Cada livro fica em sua própria pasta. Cada pasta de livro tem um **README próprio**, com o laboratório e as instruções específicas daquele livro.

## Como baixar

**Com git (recomendado):**

```bash
git clone https://github.com/AbuAcademy/BeMyGuest.git
cd BeMyGuest/Livro3   # troque pela pasta do livro desejado: Livro1, Livro2, …
```

**Sem git:** clique no botão verde **Code → Download ZIP**, extraia o arquivo e entre na pasta do livro.

## Aviso

Material educacional de segurança ofensiva e defensiva. Execute apenas em **laboratório isolado** e em sistemas sob sua **autorização**. Em alguns livros você vai se deparar com exemplos que contêm **falhas intencionais**, para estimular o hacker que existe dentro de você.
